# Changelog

This changelog tracks MACE-Field-specific releases. Changes inherited from the
MACE core are maintained by the [upstream MACE project](https://github.com/ACEsuit/mace).

## 1.1.0 — unreleased

- Add release automation and retain the `mace` Python import namespace.
- Add HDF5 support for Hessian-labelled training data and improve field-response
  training, validation, and loss handling.
- Add contributor guidance and release documentation.

## Previous releases

The initial implementation and subsequent MACE-Field updates are archived in
the [GitHub releases](https://github.com/mdi-group/mace-field/releases),
including versions `v1.0`, `1.0.1`, and `1.0.2`.
